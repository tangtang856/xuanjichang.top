macOS平台客户端配置与系统代理设置教程

更新时间：2026-03 适配客户端：Clash Verge Rev (Mac) / Surge for Mac 实操验证：已在最新系统环境下测试通过

专为苹果 Mac 电脑（M1/M2/M3/M4 Apple Silicon 芯片及 Intel 架构）打造的科学上网指南。推荐使用原生的 Clash Verge Rev Mac 版，兼具极简美观与高效分流。

📌 30秒极速上手速记

配置科学上网的通用逻辑非常纯粹：【下载正规客户端】→【在机场后台复制订阅URL】→【在客户端中导入并拉取节点】→【选择规则分流模式并开启系统代理】。全过程通常仅需 2-3 分钟。

详细步骤分解图文教学

步骤一：下载适配您芯片架构的安装包

根据您的 Mac 处理器架构下载对应版本：Apple Silicon（M1/M2/M3/M4）下载 aarch64.dmg；旧款 Intel 处理器下载 x64.dmg。将应用拖入“应用程序”文件夹。

步骤二：解决“已损坏”或“未知开发者”提示

macOS 安全机制可能会提示无法验证开发者。请进入 Mac 的“系统设置 -> 隐私与安全性”，找到底部“仍要打开”按钮并允许运行。

步骤三：导入订阅并配置智能分流

在 Clash Verge 中添加订阅链接并更新成功后，模式建议选择“规则（Rule）”，并在设置中开启“系统代理（System Proxy）”。

步骤四：配置开机自启与静默托盘运行

在通用设置中勾选“开机自启动”和“最小化到状态栏”，Mac 电脑在顶部菜单栏即常驻小图标，方便随时切换节点与查看网络上传下载速率。

常见故障排查与使用问答 (FAQ)

Terminal终端或命令行为什么没有走代理？ +
GUI 客户端默认只代理支持系统代理设置的浏览器及常用应用。终端环境需在 Clash Verge 中开启“TUN 模式”，或在终端配置 export http_proxy 环境变量。
