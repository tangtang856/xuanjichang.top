Docker Pull 镜像拉取超时解决：配置 Daemon 代理指南

最后更新：2026-03 适配工具：Docker Desktop / Linux Docker 实测状态：已在最新操作系统环境下实操验证

国内 Docker Hub 镜像中心受限后，如何为 Docker 守护进程配置正规代理通道，实现海外镜像毫秒级拉取。

📌 30秒极速配置核心思路

科学上网客户端配置逻辑非常清晰纯粹：【下载正规正版客户端】→【在机场用户后台复制订阅URL】→【在客户端中导入并拉取节点】→【选择规则分流模式并开启系统代理/VPN】。整个流程通常仅需 2-3 分钟即可完成。

详细步骤分解图文教学

1. 修改 /etc/docker/daemon.json 或 systemd 配置

在 /etc/systemd/system/docker.service.d/http-proxy.conf 中写入 HTTP_PROXY 与 HTTPS_PROXY 环境变量。

2. Docker Desktop 图形化设置

在 Docker Desktop 设置 -> Resources -> Proxies 中开启 Manual proxy configuration，填入本地代理端口。

3. 重启 Docker 服务验证拉取

执行 systemctl daemon-reload && systemctl restart docker，随后拉取 gcr.io 或 k8s 镜像秒级下载。

常见故障排查与使用问答 (FAQ)

容易误代理本地局域网吗？ +
请在 NO_PROXY 中添加 localhost,127.0.0.1,192.168.0.0/16 避免局域网流量被拦截。
