程序员必看：Git 与命令行终端代理环境配置全攻略

最后更新：2026-03 适配工具：Git / Terminal (macOS/Linux/Windows) 实测状态：已在最新操作系统环境下实操验证

解决 git clone 频繁超时、Failed to connect to github.com 报错。教您为 Git 协议与系统终端配置极速代理通道。

📌 30秒极速配置核心思路

科学上网客户端配置逻辑非常清晰纯粹：【下载正规正版客户端】→【在机场用户后台复制订阅URL】→【在客户端中导入并拉取节点】→【选择规则分流模式并开启系统代理/VPN】。整个流程通常仅需 2-3 分钟即可完成。

详细步骤分解图文教学

1. 为 Git 配置全局 HTTP 代理

在终端执行命令：git config --global http.proxy http://127.0.0.1:7890 及 https.proxy http://127.0.0.1:7890。

2. 为 SSH 协议克隆配置 ~/.ssh/config

在 ~/.ssh/config 中针对 github.com 增加 ProxyCommand 走本地 Connect 命令转发。

3. 终端临时环境变量加速

配置 alias proxy="export http_proxy=http://127.0.0.1:7890; export https_proxy=http://127.0.0.1:7890"，随时一键加速。

常见故障排查与使用问答 (FAQ)

如何取消 Git 代理设置？ +
执行 git config --global --unset http.proxy 即可恢复默认直连。
