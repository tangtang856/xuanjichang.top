开启代理后浏览器频繁提示“证书无效/您的连接不是私密连接”根因与解决

最后更新：2026-03 作者：选机场网编辑部 实操评测：已核验线路与品牌数据
💡 本文核心要点速览

NET::ERR_CERT_COMMON_NAME_INVALID 怎么破？揭秘杀毒软件中间人扫描、系统根证书冲突与代理软件端口劫持排查全流程。

令人抓狂的红色警报：“您的连接不是私密连接”

许多用户在开启翻墙软件后，打开 Chrome 或 Edge 浏览器访问网站时，页面没有正常加载，反而弹出一个巨大的红色叹号：“您的连接不是私密连接 (NET::ERR_CERT_AUTHORITY_INVALID)”，无论怎么点击刷新都进不去网页。这往往给新手带来极大的安全恐慌。

三大核心诱发根因剖析

1. 第三方杀毒软件（360 / 火绒 / 卡巴斯基）的“网页防护”中间人拦截

很多杀毒软件开启了“HTTPS 网页内容扫描”功能。为了扫描加密网页，杀毒软件在本地强行植入了自己的自签中间人根证书。当这种自签证书与代理客户端的本地流量转发发生冲突时，浏览器会触发严格的安全防御机制并直接拒绝访问。

解决办法：在杀毒软件设置中，暂时关闭“网络保护/HTTPS 扫描”选项，或者将 Clash/v2rayN 加入信任白名单。

2. 客户端错误开启了 MITM（中间人解密）或去广告插件

在 Shadowrocket 或 Loon 等客户端中，如果你导入了第三方复杂的去广告规则或脚本，这些规则需要解密 HTTPS 流量，但你没有在操作系统中信任并安装客户端生成的 CA 根证书。

解决办法：在客户端设置中关闭“HTTPS 解密 (MITM)”开关，或者在手机“通用 -> 关于本机 -> 证书信任设置”中完全信任该证书。

3. 电脑主板时间被篡改

检查右下角系统时间，确保年份、月份和分钟完全准确无误。
