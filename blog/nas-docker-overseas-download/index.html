💡 本文核心要点速览

群晖TMDB电影海报刮削失败、红叉断图？Docker容器无法拉取？针对NAS高级玩家，讲透网络代理与家庭私有云影视库搭建。

家庭影院的核心基石：海报墙与自动刮削

对于组建了群晖（Synology）、威联通（QNAP）或自建 Unraid / TrueNAS 的影音发烧友而言，最爽快的事情莫过于看到 Plex、Emby 或 Jellyfin 将下载的电影自动匹配出高清电影海报、演员表、剧情简介和烂番茄评分（俗称刮削）。

但现实中很多人却面临大量红叉：TMDB（The Movie Database）的 API 接口在大陆公网长期处于 DNS 污染与连接阻断状态，导致后台刮削任务全面停摆。

在群晖 NAS 中优雅配置代理的两种方案

方案一：通过 Docker 部署独立 Clash 客户端

在群晖 Container Manager（Docker）中拉取 dreamacro/clash 镜像，映射本地端口 7890，并将机场订阅作为配置文件载入。随后在群晖控制面板 -> 网络中，勾选“通过代理服务器连接”，填入 127.0.0.1:7890，即可让 NAS 基础系统秒开海报刮削。

方案二：全屋软路由旁路由接管（最强推荐）

将 NAS 的默认网关直接指向局域网内的 OpenWrt 旁路由。NAS 本身无需进行任何侵入式软件修改，刮削数据自动走专线代理，而大容量 PT 本地内网传输和国内直连下载完全不受影响，省心且优雅。
