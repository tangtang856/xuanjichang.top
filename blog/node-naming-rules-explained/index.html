节点列表里的“天书”缩写

初次导入机场订阅的新手，面对客户端里密密麻麻几十个节点往往一头雾水：🇭🇰 香港 01 | [1.0x] | BGP-IEPL-HKT | 流媒体解锁，这些花里胡哨的符号与英文字母到底传达了哪些关键信息？

节点命名各字段的工业标准解码

  1. 国家与地区 Emoji 旗帜：直观代表该落地服务器所在的地理区域（🇭🇰 香港、🇯🇵 日本、🇸🇬 新加坡、🇺🇸 美国、🇹🇼 台湾、🇬🇧 英国）；
  2. 倍率标识（如 [1.0x]、[0.1x]、[3.0x]）：计费放大的系数。1.0x 代表扣除真实流量；0.1x 代表流量打一折（下载神器）；3.0x 代表扣除三倍流量（昂贵高端专线）；
  3. 线路架构代号：
    • BGP：国内入口采用多线多网直连机房；
    • IEPL / IPLC：跨国内网物理光纤专线，晚高峰零丢包不经过公网防火墙；
    • Transit / Relay：公网加密隧道中转线路；
  4. 海外落地运营商代号：如 HKT（香港电讯盈科原生家庭宽带）、Hinet（台湾中华电信原生宽带）、NTT / SoftBank（日本主流骨干民用网络）；
  5. 冷备 / 故障转移代号（Backup / Cold）：平时备用不承载主力流量，仅当主线路遭遇机房割接维护时自动顶上的应急节点。
