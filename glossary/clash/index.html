术语百科：什么是Clash？规则分流与主流客户端生态

最后修订：2026-03 收录机构：选机场网术语百科中心 分类标签：客户端生态
📖 概念一句话速览

Clash 是当代科学上网领域最伟大的开源规则代理分流核心。本文全面梳理从原生 Go 内核到 Mihomo (Meta) 的演进，以及 Clash Verge、Clash for Windows 等客户端生态。

一、Clash 的核心本质：基于规则的代理内核

Clash 本质上并不是一个图形界面的“软件”，而是一个由开发者 Dreamacro 使用 Go 语言编写的无界面命令行代理分流引擎（Core）。它的最大革命性创新在于引入了强大的 YAML 配置文件与自动化策略组机制。

二、策略组与智能分流的运行机制

在 Clash 中，用户可以定义各种规则集（Rule Sets）：

  • DOMAIN-SUFFIX,google.com,PROXY：访问包含 google.com 的域名，自动走代理；
  • GEOIP,CN,DIRECT：所有位于中国大陆境内的 IP 地址，自动直连；
  • MATCH,PROXY：所有未被上述规则匹配的兜底流量走代理。

这种机制彻底改变了过去“要么全翻、要么全断”的粗暴模式，实现了国内国外无感混用。

三、内核停更与 Mihomo (Clash Meta) 的崛起

2023年下旬，原版 Clash 内核及 Clash for Windows 作者停止了维护。随后开源社区迅速集结，诞生了 Mihomo（亦称 Clash Meta） 项目。Mihomo 全面继承并扩充了原版协议，原生支持了 VLESS、Reality、Hysteria 2、TUIC 等新兴尖端协议，成为了当前事实上的行业新标准。目前主流的桌面客户端 Clash Verge Rev 即默认基于 Mihomo 内核打造。
